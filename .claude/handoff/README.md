# Hand-offs

One file per milestone: `YYYY-MM-DD.md` (add `-b`, `-c` for more on one day). A new session reads
the latest one instead of the old conversation (see the `usage-budget` skill).

Template:

```md
# Hand-off YYYY-MM-DD — <topic>

## Done
- …

## Open jobs
- <job> — files / Figma node ids / script that resumes it

## Waiting on a decision
- <question> — options, recommendation

## Next step
- …
```
