How This Works

  1. 1. The page calls a Cloudflare Worker, not Brevo directly.
  2. 2. The Worker creates a short-lived token and stores it in Workers KV.
  3. 3. The Worker sends the email through Brevo using server-side secrets.
  4. 4. The email link returns to this page with the token in the URL.
  5. 5. This page sends the token back to the Worker for verification.
